AIRBNB LISTING ANALYSIS - STREAMLIT

1. Open a terminal in this folder.
2. Install dependencies:
   py -m pip install -r requirements.txt
3. Generate the dataset:
   py generate_data.py
4. Start the app:
   py -m streamlit run app.py

Pages: Overview, Web scraping, EDA, Distributions, Central Limit Theorem,
Hypothesis tests (Z, T, Chi-square, ANOVA), Regression (Simple, Multiple,
Ridge, Lasso) and Price predictor.

Keep the .streamlit folder (it holds the colour theme) next to app.py.

Note: airbnb.csv is a reproducible synthetic dataset (generate_data.py).
The Web scraping page only lists links from Inside Airbnb and needs internet.
